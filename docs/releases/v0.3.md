Tested on an MS-60B running the MS-50G 3.10 OS.
- MIDI clock (24 ticks per beat, over USB) sets the patch tempo, the same tempo tap tempo sets. The tempo locks about 3 beats after the clock starts and follows tempo changes within a few beats, from 40 to 250 BPM.
- A steady clock never re-sends the tempo, so tempo-synced stock effects such as TapeEcho stay smooth. Some stock delays (for example Delay) restart their echoes whenever the tempo changes, just as they do with tap tempo.
- Start/stop/continue are ignored. Tapping a tempo by hand while the clock runs holds until the clock tempo changes or the clock restarts.
- Keeps v0.2: MIDI Program Change loads patches, MIDI CC switches effects and turns knobs.
- The menu shows MOD 0.3.
- MS-50G 3.10 OS only for now. Build it with: zoomms build <MS-50G 3.10 updater> --patch patches/version-0.3.yaml --patch patches/midi-cc.yaml --patch patches/midi-clock.yaml --build-id ms50g-3.10 --out build/out/ms50g-3.10-mod0.3-midiclock.exe (see docs/flashing.md).
