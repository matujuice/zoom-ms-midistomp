# MIDISTOMP MOD v2.0.3

Made alongside **[effects pack v2.0.3](https://github.com/matujuice/zoom-ms-zdl-effects-pack/releases/tag/v2.0.3)**.

**Effects pack v2.0.3:** Washout is rebuilt as a one-knob washout (Wash, Tone, Size). It no longer clicks or slows the pedal in a busy chain. The live meters of Gooey and LOUDER now also run on the MS-50G firmware 3.10.

**Firmware**
- **Identity tag:** the pedal answers a MIDI identity request with `M203`, so editors can tell a MIDISTOMP pedal from a stock one. Zoom Effect Manager still works.
- The pedal's own fonts are read from Zoom's OS instead of being copied into MIDISTOMP. The screens look the same.

**Install:** same as v2.0. Download **MIDISTOMP-builder-Windows.exe** below and drop Zoom's official **MS-70CDR v2.10** Windows updater on it (also for the MS-50G and MS-60B), then run the `MIDISTOMP V2.0 Updater.exe` it writes. On a Mac, use **MIDISTOMP-builder-Mac-AppleSilicon.zip** or **MIDISTOMP-builder-Mac-Intel.zip**: [On a Mac](https://github.com/matujuice/zoom-ms-midistomp/blob/main/docs/user-guide.md#on-a-mac). Recovery: Zoom's original updater. The pedal's menu shows **V2.0.3** on MENU > SYSTEM.

No download here contains Zoom's code: the builders make the MIDISTOMP updater from your own copy of Zoom's.

Bugs and ideas: [issues](https://github.com/matujuice/zoom-ms-midistomp/issues). Have fun!
