# MIDISTOMP MOD v2.0.2

A small release to match **[effects pack v2.0.2](https://github.com/matujuice/zoom-ms-zdl-effects-pack/releases/tag/v2.0.2)**. The firmware is the same as v2.0.1.

**Effects pack v2.0.2 fix:** stock delays and reverbs no longer go silent or burst after a pack effect has run. Choral and GRDLOOP now stay inside the memory the pedal gives them. Update the pack if you use Choral or GRDLOOP.

**Version numbers from now on:** the pedal's boot screen and menu say **v2.0** for every 2.0 bugfix release, and so do the README pictures. The exact release shows on MENU > SYSTEM (**V2.0.2**) and in the updater's window title.

**Install:** same as v2.0. Download **MIDISTOMP-builder-Windows.exe** below and drop Zoom's official **MS-70CDR v2.10** Windows updater on it (also for the MS-50G and MS-60B), then run the `MIDISTOMP V2.0 Updater.exe` it writes. On a Mac, use **MIDISTOMP-builder-Mac-AppleSilicon.zip** or **MIDISTOMP-builder-Mac-Intel.zip**: [On a Mac](https://github.com/matujuice/zoom-ms-midistomp/blob/main/docs/user-guide.md#on-a-mac). Recovery: Zoom's original updater. Coming from v2.0.1, you don't need to flash again.

No download here contains Zoom's code: the builders make the MIDISTOMP updater from your own copy of Zoom's.

Bugs and ideas: [issues](https://github.com/matujuice/zoom-ms-midistomp/issues). Have fun!
