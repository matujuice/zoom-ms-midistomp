# MIDISTOMP MOD v2.0.4.1

A fix release for v2.0.4, made alongside **[effects pack v2.0.4.1](https://github.com/matujuice/zoom-ms-zdl-effects-pack/releases/tag/v2.0.4.1)**. Same features; fixes from a code audit.

**Firmware**
- **PERFORM SETUP after a patch change:** changing to a patch with fewer effects while a target pick was open made SETUP read past the end of a table. SETUP now goes back to its top screen when the patch changes.
- **MIDI CC to an empty effect slot:** a CC mapped to a slot with no effect could freeze the pedal. It is now ignored.
- **PERFORM grid clock:** a beat could land up to half a beat early after a tempo jump. Fixed.

**Builder**
- If the builder hits an unexpected error (a failed write, say), it prints it and waits for Enter instead of closing at once.
- Safety check: a firmware patch write must be the same length as the stock bytes it replaces.

Tested on an MS-70CDR at 360 MHz.

**Install:** as v2.0.4. Download **MIDISTOMP-builder-Windows.exe** below and drop Zoom's official **MS-70CDR v2.10** Windows updater on it (also for the MS-50G and MS-60B); it writes **MIDISTOMP V2.0 Updater.exe** (stock clock, the safe default) and **MIDISTOMP V2.0 Updater (360MHz OC).exe** (360 MHz). Run whichever one you want flashed. On a Mac, use **MIDISTOMP-builder-Mac-AppleSilicon.zip** or **MIDISTOMP-builder-Mac-Intel.zip**: [On a Mac](https://github.com/matujuice/zoom-ms-midistomp/blob/main/docs/user-guide.md#on-a-mac). Recovery: Zoom's original updater. The pedal's menu shows **V2.0.4.1** on MENU > SYSTEM.

No download here contains Zoom's code: the builders make the MIDISTOMP updater from your own copy of Zoom's.

Bugs and ideas: [issues](https://github.com/matujuice/zoom-ms-midistomp/issues). Have fun!
