# MIDISTOMP MOD v2.0.4.2

A builder release for v2.0.4.1. Same firmware features; the builder now knows which pedal you have ([issue 79](https://github.com/matujuice/zoom-ms-midistomp/issues/79)).

**Builder**
- **Pick your pedal:** after you drop in Zoom's updater, a window asks which pedal you will flash (MS-70CDR, MS-60B or MS-50G): click yours and press **Next**. The pedal then reports its own model to editors and to Zoom's updaters, instead of always saying MS-70CDR. MS-60B and MS-50G builds get the pedal in the file name, for example **MIDISTOMP V2.0 MS-60B Updater.exe**.
- **Mac:** the 360 MHz build's window title now fits (Zoom's title is 27 characters), and the builder says which file was written if the second build fails.

Tested on an MS-70CDR. The Mac builders are tested end to end on GitHub's Mac machines with Zoom's own Mac updater.

**Install:** as v2.0.4.1. Download **MIDISTOMP-builder-Windows.exe** below and drop Zoom's official **MS-70CDR v2.10** Windows updater on it (also for the MS-50G and MS-60B), then pick your pedal. It writes **MIDISTOMP V2.0 Updater.exe** (stock clock, the safe default) and **MIDISTOMP V2.0 Updater (360MHz OC).exe** (360 MHz); on an MS-60B or MS-50G the names include the pedal. Run whichever one you want flashed. On a Mac, use **MIDISTOMP-builder-Mac-AppleSilicon.zip** or **MIDISTOMP-builder-Mac-Intel.zip**: [On a Mac](https://github.com/matujuice/zoom-ms-midistomp/blob/main/docs/user-guide.md#on-a-mac). Recovery: Zoom's original updater. The pedal's menu shows **V2.0.4.2** on MENU > SYSTEM.

No download here contains Zoom's code: the builders make the MIDISTOMP updater from your own copy of Zoom's.

Bugs and ideas: [issues](https://github.com/matujuice/zoom-ms-midistomp/issues). Have fun!
