# MIDISTOMP MOD v1.2

**New**
- **One build for every pedal:** v1.2 is made from Zoom's **MS-70CDR 2.10** firmware and runs on the MS-50G, MS-60B and MS-70CDR. One builder, one Zoom updater for all three.
- **Stereo input on the MS-70CDR.** The MS-50G and MS-60B run it with mono input, as before.
- **Updates from any firmware:** the updater works whatever the pedal runs now (stock MS-50G, MS-60B or MS-70CDR firmware, or MIDISTOMP v1.0/v1.1). Zoom's own MS-70CDR updater would refuse a pedal on MS-50G firmware ("Illegal device connected").
- Your installed effects and patches are kept.
- Same features as v1.1: MIDI CC (with CC 80/81 patch up/down), MIDI clock and Start/Stop, MIDI menu, tempo screen, HOLD FOR, button combos, faster scrolling. Boot screen and VERSION entry read **v1.2**.

**Tested** on an MS-60B and an MS-70CDR, including updating a pedal that ran the MS-50G firmware.

**Install:** download MIDISTOMP-builder.exe below, drop Zoom's official **MS-70CDR v2.10** Windows updater on it (use it for the MS-50G and MS-60B too), and run the `MIDISTOMP V1.2 Updater.exe` it writes. Recovery: Zoom's original updater. Full steps: docs/user-guide.md.

**Mac:** no Mac builder in v1.2 yet; Mac users stay on [v1.1](https://github.com/matujuice/zoom-ms-midistomp/releases/tag/v1.1).
