# v2.0.1 bug list (Luca's pedal tests after the v2.0 release, 2026-11-06)

## Firmware: Perform mode

1. **Perform bar blinks out of step.** The cycle bar blinks unevenly. The bottom button's countdown (when it is on a footswitch with a Next value) is drawn on the cycle bar, and that countdown blinks evenly and in sync. Likely cause: two sources drive the same bar (the cycle and the button countdown).
2. **Bottom-button countdown is on the wrong bar.** A footswitch-assigned bottom button with a Next value counts down on the Perform cycle bar instead of on its own button. Probably the same root cause as 1.
3. **Next values: remove the cycle fractions.** Next should mean "next bar / next 2 bars from the press". Keep the bar values as they are now and remove the cycle-fraction values.
4. **Follow action fires on the press.** It must fire when the action completes, as designed.
5. **A queued bottom-button action is lost when the looper finishes an action.** Example: record 8 bars, press the bottom (cursor) button for a filter set to Next 4 bars. When the recording ends, the loop plays but the filter never fires. Only the bottom cursor button does this.
6. **Bottom-button Hold follows Next.** With Hold set to Now, it still waits for the Next value.
7. **Knob values show 0..200.** A Perform knob must show the same range and units as the knob it targets.
8. **Turning a knob drops its queued reset.** A knob on a filter whose press resets it to 0 at Next 4 bars: press it (reset queued), keep turning it, and the reset is forgotten. Turning must keep the queued reset.
9. **Looper bar shows on the GRDLOOP knob pages.** It appears only on the looper's own effect page. Recent commits: ac2c8ff, f00396d.

## Whine (~5.5 kHz) on stock and modded pedals

44.1 kHz / 8-sample block = 5.5125 kHz, with a harmonic near 11 kHz. This is the DSP's per-block current draw coupling into the analog stage, a stock hardware trait. Firmware can't remove it cleanly: the block size is fixed, and a notch filter cuts the audio band. What helps: an isolated PSU, batteries, a ferrite, no USB power, a gate or ZNR last, and lower DSP load.

Our part: keep audio-path CPU low, and never step a gain or parameter once per block without smoothing it inside the block, because a per-block step adds its own 5.5 kHz component.
